## 作品方向

從日常學習與生活觀察出發，製作單字練習工具、T 字路口交通號誌模擬、坡地雨量警戒模擬、慢箋領藥日期試算、三同藥品資料查詢及家庭分路用電監測原型。

各作品以專案頁面中的 README、操作頁面和可查閱資料，區分已完成的軟體功能及尚未進行的實體硬體驗證。交通、雨量、家庭配電箱等模擬皆非實際安全監測或控制設備；藥品查詢與領藥日期工具亦不能替代藥師的專業核對。

這是靜態網站。GitHub Pages 可設定為 `main` 分支的 `/(root)`，以根目錄 `index.html` 作為入口。`batch-1/evidence`、`batch-2/evidence`、`batch-3/evidence` 等資料夾保存網站所引用的原始證據。上傳或移動附件時，應保留相對路徑。

## 資料呈現原則

競賽團體成果與個人成果分開標示；軟體模擬不宣稱為實體感測或工程驗證。成績、證書與參與情形以對應佐證為準。未公開的草稿與素材整理紀錄不放入正式作品網站。
